# SPORTIVA — Sport Equipment Store

Website katalog toko perlengkapan olahraga umum yang dibuat sebagai proyek UTS Pemrograman Web 2026.

---

## Tentang Aplikasi

**SPORTIVA** adalah website katalog yang menampilkan berbagai produk perlengkapan olahraga. Pengunjung dapat memasukkan nama pada halaman Login simulasi, melihat Dashboard, membuka halaman Profile, serta menjelajahi seluruh katalog produk.

Website ini **bukan** toko online, jadi tidak ada transaksi, keranjang belanja, maupun database.
